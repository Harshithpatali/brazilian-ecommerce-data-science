# Statistical Analysis Plan

The SQL layer prepares analysis-ready data; Python performs formal statistical tests.

Priority hypotheses:

1. Delivery delay is associated with lower review score.
2. Customer segments differ materially in purchase frequency and monetary value.
3. Cohorts differ in retention.

For high-quality analysis:
- define the hypothesis before looking at the result
- choose the test based on the data-generating assumptions
- report effect size and uncertainty, not only p-value
- avoid causal language unless the study design supports causality
- for multiple comparisons, consider false-discovery-rate control
