Use Python on analysis-ready SQL outputs. Report hypotheses, effect sizes and uncertainty.

Replace the baseline one-time/repeat proxy with a point-in-time future-window churn label, then train and compare models.

## Phase 8 — Product
Generate dashboard datasets and run Streamlit.

## Phase 9 — Portfolio
Add screenshots, final findings, SQL examples, model metrics and business recommendations to the README.
